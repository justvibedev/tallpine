---
title: Terminal surface
description: The built-in desktop terminal backed by Tallpine's WebSocket mux.
---

Open the Terminal pane in a session to use Tallpine's built-in desktop terminal. Tallpine does not select between terminal plugins.

Terminal UI sessions attach to the platform runtime: native PTY hosts on macOS and Linux (tmux for legacy or fallback sessions) and ConPTY on Windows. Chat sessions can open a separate shell in the same session worktree.

See [desktop terminal](/plugins/terminals/web) for connection behavior.
