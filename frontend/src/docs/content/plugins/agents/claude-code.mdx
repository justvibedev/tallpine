---
title: Claude Code
description: Built-in Terminal UI and structured Chat support for the user's Claude Code installation.
---

Tallpine resolves the `claude` executable from your machine and reuses its existing authentication. Install and sign in with Claude Code before refreshing the Tallpine catalog.

```bash
tallpine agent ls --refresh
tallpine spawn --project my-app --name claude-task --agent claude-code --mode chat
```

## Interfaces

- **Terminal UI:** runs the native Claude Code CLI in the session worktree.
- **Chat:** uses Tallpine's ACP transport with `claude-agent-acp`, pointed at your Claude executable.

Claude Code is one of the harnesses that can move between Chat and Terminal UI without changing the Tallpine session or worktree. Idle sessions can switch directly; the desktop shows the supported finish/stop policy for a busy controller. Follow the switch dialog, including any draft or queued-message warning.

Tallpine installs its supported activity hook during workspace setup. Use `tallpine agent ls --refresh --json` for install/auth diagnostics rather than editing a plugin block.

## Models, effort and review

`tallpine spawn --model <model>` and `--effort <level>` override the model and reasoning effort for one session without changing the project's configuration. Claude Code is also a reviewer harness, and it is the fallback reviewer when a project configures none and the worker's harness cannot review. See the [review loop](/guides/review-loop).
