---
title: Workspaces
description: Git worktrees for repositories and Tallpine-managed directories for Scratch projects.
---

Workspace behavior follows the registered project kind:

| Project kind | Session workspace |
| --- | --- |
| Git repository | A fresh [Git worktree](/plugins/workspaces/worktree) and branch. |
| Multi-repository workspace | A root worktree with registered child repositories materialized for the session. |
| Scratch | A Tallpine-managed directory with no branch or PR operations. |
| Standalone worker | A projectless Tallpine-managed directory; no project, issue, branch, or PR options. |

Tallpine does not currently offer a full-clone workspace selector. Register a project with `tallpine project add`, then let the daemon route workspace operations from its project record.

Workspace cleanup is conservative: killing a session does not force-delete a dirty registered worktree. Use `tallpine session cleanup --dry-run` to inspect eligible terminated sessions.
