Tallpine is a desktop app for supervising AI coding agents. It gives each worker an isolated workspace, keeps its conversation or terminal available, and connects Git work to pull requests, CI, reviews, and merge conflicts.

The agents write the code. Tallpine helps you manage projects and sessions, follow work, send instructions, review changes, and open browser previews.

<Callout type="info" title="Fastest path">
	Download the desktop app, add a repository, and start one small session. See [Installation](/installation), then [Quickstart](/quickstart).
</Callout>

<span id="what-tallpine-helps-you-do" />
## What Tallpine helps you do

- Run several coding agents without mixing their files, branches, or pull requests.
- Choose a native terminal UI or structured Chat for each session.
- Follow activity, CI, review feedback, and merge readiness from the desktop app.
- Send follow-up instructions to the right worker.
- Run reviewer agents and route requested changes back to the worker.
- Preview a session's local app beside its Chat or terminal.
- Schedule recurring work with Automations and reuse project instructions or shell commands with Cues.
- Check and respond from the companion mobile app through Connections.

Tallpine works best when each worker has a clear, reviewable outcome: a focused bug, feature, refactor, test, documentation update, or review follow-up.

## The basic loop

```text
add project -> start session -> isolated worktree -> pull request -> CI/review -> merge -> cleanup
```

Create sessions from the desktop app or the optional CLI. Tallpine starts the selected agent interface and combines saved activity and pull-request data to show a session's status.

## Chat and Terminal UI

Every session has one active agent interface at a time:

| Interface | Best for |
| --- | --- |
| **Chat** | Structured messages, activities, approvals, plans, usage, and conversation history. |
| **Terminal UI** | The agent harness's native interactive terminal experience. |

Chat support depends on the harness and installed version; see the [agent capability catalog](/plugins/agents#chat-versus-terminal-ui). Compatible sessions can switch interfaces without changing their session or worktree; the UI shows which transitions are available.

## Where local data lives

<span id="local-by-design" />

The desktop app runs a Go background service and talks to it through a local API over a Unix socket only your user can open (loopback `127.0.0.1` on Windows). Tallpine stores app data and worktree metadata under `~/.tallpine` by default. Most integrations use coding agents and source-control credentials already on your computer; Tallpine does not bundle external agents or their credentials. Unreal Agent is a built-in Chat-only adapter on macOS and Linux.

Connections is a separate, opt-in listener protected by a pairing code. See [Connections](/configuration/remote-access) for local and secure remote pairing.

This manual tracks `main`; no tagged Tallpine release exists yet. Newer controls on `main` may differ from that release. Check the [changelog](/changelog) and its release notes before using a new control.

## Supported agents

Tallpine supports the coding agents Claude Code, Codex, Kiro, and DeepSeek. Their support for worker, Chat, and reviewer roles varies. Check the [agent catalog](/plugins/agents) for details.

GitHub and GitLab provide source-control observation and issue intake. Intake is opt-in and read-only toward the issue tracker; Linear and legacy Node plugin packages are not supported.
