### `tallpine backlog run`

```text
Run mode keeps one durable run per project: the plan (lanes of items, a model each), every item's progress, and the end summary. The orchestrator writes the plan and the progress; the Backlog page reads them. On by default; TALLPINE_BACKLOG_RUN=off on the daemon turns it off.

Usage:
  tallpine backlog run [command]

Available Commands:
  finish      End the run with your summary (landed / waiting on the owner / held)
  item        Record one planned item's progress

  resume      Resume a paused run
  start       Create a run for all open items, some items, or one parent's children
  status      Show a run (default: the open run) with its plan and progress
  stop        Finish the work in flight and start nothing new
```

### `tallpine browser act`

```text
Snapshots, finds the best-matching element for <instruction> against role/name/text
(no LLM call — deterministic matching, same as reading a snapshot yourself), and performs
--action on it (default click). Retries once on a stale reference. If the match is
ambiguous or absent, returns the candidates or snapshot instead of guessing — fall back
to a manual snapshot/click, retry with --nth, or refine the instruction.

Usage:
  tallpine browser act <instruction> [flags]

Flags:
      --action string               verb to perform on the matched element (click, dblclick, focus, hover, fill, type, check, uncheck) (default "click")
      --expect-dialog               wait for a pending confirm or prompt dialog after dispatch
      --expect-dom-change           wait for the accessibility snapshot to change after dispatch
      --expect-navigation           wait for a main-frame or in-page navigation after dispatch
      --expect-text string          wait for this page text after dispatch
      --expect-url string           wait for a URL containing this value after dispatch
      --nth int                     0-based index to disambiguate when multiple candidates match equally
      --postcondition-timeout int   postcondition timeout in milliseconds (default 10000)
      --value string                text to fill/type; required when --action is fill or type

Global Flags:
      --json   print the structured response as JSON
```

### `tallpine session land`

```text
Land a worker branch that has no PR (orchestrator or owner only; workers are refused).

1. Refuses a session that tracks a PR (use tallpine pr land).
2. Requires the newest native review of the branch to approve its current head.
3. Squashes the branch into one commit on the target: --into, else the project's
   default branch. The message carries Tallpine-Session and Tallpine-Head
   trailers; landing the same head again is a no-op.
4. Refuses a conflict (listing the files) and a checkout of the target with
   staged or modified tracked files. The target moves only by compare-and-swap
   and a clean checkout of it is fast-forwarded.
5. With a hosted remote, pushes the commit to origin without force (a moved
   remote rejects it and nothing moves), then fast-forwards the local target.

--dry-run prints the decision and moves nothing. --kill-worker ends the worker
after a successful land.

Usage:
  tallpine session land <session> [flags]

Flags:
      --dry-run       print the decision without moving anything
      --into string   target branch (default: the project's default branch)
      --json          print the result as JSON
      --kill-worker   terminate the worker session after a successful land
```

## `tallpine spawn`

```text
Spawn an agent session in a registered project, or a standalone worker with --standalone.

The session runs the chosen agent in a
fresh isolated workspace. Git projects use worktrees; standalone agents use a Tallpine-managed plain directory.

Usage:
  tallpine spawn [flags]

Flags:
      --allow-duplicate            With --backlog, start the item even if a live session already holds it (--force does not imply this)
      --backlog string             Backlog item ref (e.g. B12) to work on: its title, note, done-when and agent notes join the task, and the session is linked to it
      --branch string              Branch for git project sessions (default: tp/<session-id>/root; unsupported for standalone or Scratch sessions)
      --claim-pr string            Claim PR ownership metadata only for the spawned session; does not check out the PR branch
      --effort string              Reasoning effort override for this session only (e.g. low, medium, high); empty defers to the agent/model default
      --force                      With --backlog, start the item even if it is held
      --harness string             Agent harness / --agent: claude-code, codex, kiro, deepseek-harness (default: project worker.agent; orchestrator spawns default to project orchestrator.agent; required if the project has none)
      --issue string               Issue id to associate with the session
      --kind string                Session role: worker or orchestrator (default: worker)
      --mode string                Initial session interface: chat (structured agent connection) or tui (the agent's native terminal). Omitted uses the daemon default; compatible sessions can switch later.
      --model string               Agent model override for this session only (exact ID; see tallpine agent models); overrides project/role config without changing it
      --name string                Display name shown in the sidebar (required, max 100 characters)
      --no-takeover                Refuse if another active session owns the claimed PR (requires --claim-pr)
      --output string              Deliverable for the session: artifact asks the agent to write a file in its artifact directory instead of opening a PR (default: ordinary task)
      --plan tallpine plan start   With --backlog, who plans an item that needs a plan: in-place (the spawned implementer writes the plan, waits read-only for approval, then builds; needs the project's planInPlace setting) or separate (a planner session via tallpine plan start). Default: follows the project's planInPlace setting
      --project string             Project id to spawn the session in (default: TALLPINE_PROJECT_ID or the current registered repo)
      --prompt string              Initial prompt for the agent
      --role tallpine plan         Special worker role: planner starts a read-only planning session that submits through tallpine plan (implies --output artifact)
      --skip-agent-check           Skip CLI readiness warnings (the daemon still validates launch readiness)
```
